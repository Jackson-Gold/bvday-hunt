♡ Hash a password

Type a password — get the SHA-256 hash to paste into assets/js/content.js.

—
How it works
Your password is trimmed and lowercased before hashing, so casing and spaces don't trip up the person solving the hunt. The same normalization happens when they type the answer on the site. The hash never leaves your browser.

Where to paste
Open assets/js/content.js and replace one of the passwordHash values (or the masterPasswordHash) with the hash above. Then commit and push — GitHub Pages will rebuild automatically.
